# GD Plist Editor

A visual Geometry Dash PLIST editor created with Claude.

Edit Geometry Dash spritesheets directly through an interactive HTML interface. Load your PNG and PLIST files, modify sprite data visually, preview your changes, and export the results.

## Features

- Visual Editor: view and edit sprites directly on the canvas.
- Sprite Editing: adjust positions, sizes, offsets, and rotation. Type exact numbers or drag the handles.
- Group Snap: sprite boxes snap to nearby boxes with guide lines.
- Sprite Management: select, copy, rename, and delete sprite entries. Search the list and step through groups with Next and Previous.
- Preview: a game preview and an animation preview.
- Pre-test Check and Compare: find mistakes in your plist and see what changed from the original.
- Pack Builder: add sheets, open a texture pack zip, and make a new texture pack.
- Helper: a built-in offline helper with commands.
- Undo and Redo, Autosave, and custom keybinds.
- Export: download the edited PLIST and image, or a single sprite as a PNG.

## How to Use

1. Download the Android app (.apk) from the Releases page, or open the offline website: https://gamerskav3-gd.github.io/
2. Load your PNG spritesheet and the matching PLIST file.
3. Select a sprite from the canvas or the sprite list.
4. Edit its properties with the controls.
5. Preview your changes and check the sprite boundaries.
6. Download your edited files.

## Install

- **Android:** download the .apk from Releases and tap it. Allow installing from this source. If Play Protect shows a warning, tap Install anyway.
- **Any phone or computer:** open the website in Chrome and choose Install app (or Add to Home Screen on iPhone). After the first visit it works offline.

## Notes

- Use matching PNG and PLIST files for accurate sprite positioning.
- Only XML PLIST files work. Binary plist (bplist) files are not supported.
- The editor works offline after the first open. The 🤖 Claude helper only works inside Claude.
- The editor preview may differ slightly from the actual game. Test your files in the game.
